# Практическая работа №3: Ассемблер и интерпретатор УВМ (Вариант №4)

CLI-ассемблер и интерпретатор для учебной виртуальной машины (УВМ) с
раздельной памятью команд и данных и языком ассемблера в алгебраическом стиле.
Реализация выполнена на **Python 3** (только стандартная библиотека).

## Структура репозитория

```text
Практическая3/
├── src/
│   ├── main.py          # CLI ассемблера (парсинг, IR, генерация байтов)
│   └── interpreter.py   # CLI интерпретатора (память, цикл УВМ, XML-дамп)
├── tests/
│   ├── spec_test.asm    # Тестовая программа по спецификации УВМ
│   ├── copy_array.asm   # Тест этапа 3: копирование массива в памяти
│   ├── test_stage1.ps1  # Скрипт проверки этапа 1
│   ├── test_stage2.ps1  # Скрипт проверки этапа 2
│   └── test_stage3.ps1  # Скрипт проверки этапа 3
├── out/                 # Генерируемые .bin и .xml файлы (игнорируется Git)
├── .gitignore
├── README.md
└── run.sh               # Скрипт быстрого запуска проверки
```

## Спецификация УВМ и язык ассемблера

Одна строка — одна инструкция, пустые строки игнорируются, комментарии
начинаются с `#`. Константы допускаются в десятичном (`879`) и
шестнадцатеричном (`0x36F`) виде. Порядок байтов — **Little-Endian**.

| Команда | `A` (0–5) | Размер | Синтаксис | Поля и диапазоны |
| :--- | :---: | :---: | :--- | :--- |
| Загрузка константы | `25` | 6 байт | `reg[C] = B` | `B` (6–33): константа `0..268435455`; `C` (34–40): регистр `0..127` |
| Чтение из памяти | `62` | 3 байта | `reg[B] = mem[reg[C]]` | `B` (6–12): регистр `0..127`; `C` (13–19): регистр-адрес `0..127` |
| Запись в память | `63` | 4 байта | `mem[B] = reg[C]` | `B` (6–22): адрес памяти `0..131071`; `C` (23–29): регистр `0..127` |
| Побитовое «не» | `21` | 4 байта | `reg[B] = ~mem[C]` | `B` (6–12): регистр `0..127`; `C` (13–29): адрес памяти `0..131071` |

### Пример программы (`tests/spec_test.asm`)

```asm
reg[7] = 879            # A=25, B=879, C=7  -> 0xD9, 0xDB, 0x00, 0x00, 0x1C, 0x00
reg[16] = mem[reg[40]]  # A=62, B=16, C=40  -> 0x3E, 0x04, 0x05
mem[920] = reg[6]       # A=63, B=920, C=6  -> 0x3F, 0xE6, 0x00, 0x03
reg[80] = ~mem[270]     # A=21, B=80, C=270 -> 0x15, 0xD4, 0x21, 0x00
```

## Запуск

**Ассемблер:**

```bash
python src/main.py <input.asm> <output.bin> [--test]
```

Пример запуска (каталог `out/` создаётся автоматически):

```bash
python src/main.py tests/spec_test.asm out/spec_test.bin --test
```

**Интерпретатор:**

```bash
python src/interpreter.py <program.bin> <dump.xml> <start:end>
```

Пример запуска:

```bash
python src/interpreter.py out/copy_array.bin out/copy_dump.xml 10:24
```

- Выполняет ассемблированный бинарный файл и сохраняет указанный диапазон
  памяти данных в формате **XML**.

**Скрипты проверки:**

```powershell
.\tests\test_stage2.ps1
.\tests\test_stage3.ps1
```
